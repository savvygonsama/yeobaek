# 여백 餘白

충동과 행동 사이에 여백을 두는 도파민 디톡스 앱(PWA).

**앱 주소: https://savvygonsama.github.io/yeobaek/**

## 흐름
1. 뇌가 도파민을 조르면 첫 화면의 원을 누른다.
2. 뇌가 속삭이는 말을 고른다. "쇼츠 딱 하나만", "과자 한 입만" 같은 것들이다.
3. 여백이 시작된다. 기본 10분이고, 설정에서 5·10·15·30분 중에 고를 수 있다. 시간이 흐르는 동안 붓으로 원(엔소)이 그려진다.
4. 그 사이 몸에게 다른 것을 준다. 스쿼트, 산책, 심호흡, 책 읽기 가운데 여러 개를 골라도 된다.
5. 끝나면 "그 욕구, 아직 남아 있나요?"라고 묻는다. 답은 셋 중 하나다.
   - **흘려보냄**
   - **여백 한 번 더**
   - **따라감**

## 기록
- 날짜와 시각, 뇌가 한 말, 대신 한 것, 결과가 건마다 영구히 쌓인다. 기록 화면에서 월별로 볼 수 있다.
- 기록은 폰 안에만 저장된다. 영구 저장을 요청해서 폰이 저장 공간을 정리할 때도 지워지지 않게 했다.
- 폰을 바꾸거나 브라우저 데이터를 지우기 전에는 **설정 → 기록 보관**에서 백업한다. 드라이브나 카톡으로 보내거나 파일로 저장할 수 있다. 새 폰에서는 **백업 불러오기**로 되살린다.

## 설치 (갤럭시)
Chrome이나 삼성 인터넷에서 위 주소를 열고, 메뉴에서 **홈 화면에 추가**를 누른다.
