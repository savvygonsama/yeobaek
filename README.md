# 잠깐

충동이 올라올 때 잠깐 미루고, 그동안 대신 할 일을 하고, 미루기에 성공한 횟수를 매일 기록하는 PWA.

**앱 주소: https://savvygonsama.github.io/jamkkan/**

## 쓰는 법
1. 쇼츠, SNS, 과자 같은 충동이 올라오면 앱을 열고 **[충동이 올라왔어]**를 누른다.
2. 뭐가 당기는지 고르면 타이머가 시작된다. 기본 10분이고, 설정에서 5·10·15·30분 중에 고를 수 있다.
3. 기다리는 동안 대신 할 행동(스쿼트, 산책, 심호흡, 책 읽기) 가운데 하나를 골라서 한다.
4. 시간이 다 되면 "아직도 하고 싶어?"라고 묻는다.
   - **괜찮아졌어**: 성공으로 기록한다.
   - **더 미룰래**: 타이머를 한 번 더 돌린다.
   - **할래**: 넘어감으로 기록한다.
5. **기록** 화면에서 날짜별 성공 횟수와 최근 14일 그래프를 본다.

## 폰에 설치 (갤럭시)
Chrome이나 삼성 인터넷에서 위 주소를 연다. 메뉴(⋮ 또는 ≡)에서 **홈 화면에 추가**(또는 **앱 설치**)를 누른다.

## 참고
- 기록은 폰 브라우저 안에만 저장된다. 서버로 보내지 않는다.
- 브라우저 데이터를 지우거나 앱을 삭제하면 기록도 함께 지워진다.
- 앱을 닫아도 타이머는 계속 간다. 다시 열면 남은 시간이나 확인 화면이 나온다. 단, 앱이 닫혀 있으면 시간이 다 돼도 알림은 오지 않는다.
